# 部署、运维与隐私

## 1. 环境依赖

| 依赖 | 说明 |
|---|---|
| Windows | 本项目在 Windows 上开发与验证（含中文路径） |
| Python 3.9 | 启动器与运维脚本（示例用 `D:\py39\python.exe`） |
| Node 20+ | Harness 与控制台；控制台壳用 Electron |
| pnpm | Harness 是 pnpm workspace |
| llama.cpp（可选） | 只有要用本地 Gemma 才需要，见《本地模型与Gemma.md》 |

**编码**：所有脚本与文档统一 UTF-8。控制台/自启脚本在 PowerShell 5.1 下必须是
**UTF-8 带 BOM**，否则中文会被按 GBK 解析导致语法错误（踩过）。

## 2. 配置文件的三个层次

| 文件 | 内容 | 是否进仓库 |
|---|---|---|
| `config/modelConfig.json` | 模型定义、定价、故障转移顺序、provider 列表 | ❌（用 `.example.json` 模板） |
| `config/secrets.json` | **唯一的密钥处**：各 provider 的 API Key、微信 token、语音凭据 | ❌ **绝对不进** |
| `config/weixinProfile.patch.yml` | 部署补丁：人格提示词、工具接线、压缩/记忆开关 | ❌（含人格，用 `.example.yml` 模板） |

**为什么拆开**：模型定义可以公开、密钥绝对不能；人格是"性格资产"，也不公开。
启动时由启动器把两者**合并**后注入 Harness（`modelConfig.json` 里指示 `secretsFile: "secrets.json"`），
控制台也只在内存里合并再返回，任何 API 都不吐密钥。

## 3. 启动与停止

```powershell
# 启动（后台，静默；会先起本地模型闸门与凭据同步）
python start_stack.py

# 停止（干净地回收 Harness、本地模型与端口）
python tools\stop_stack.py
```

启动器做的事：

1. 读 `modelConfig.json` + `secrets.json` → 合并出运行时凭据（日志只打 `refs=N`，不打明文）；
2. 同步微信 token（缺 token 会明确报"未绑定"而不是静默失败）；
3. 起 Harness（写 `runtime/harness-run.log`），起本地模型（`runtime/gemma-server.log`，独立日志便于排障）；
4. 把 Python / Node 路径记到 `config/console.env`，供控制台复用（避免控制台找不到解释器）。

## 4. 开机自启

```powershell
# 注册（两个快捷方式：控制台托盘 + 微信后端）
powershell -ExecutionPolicy Bypass -File tools\install-autostart.ps1 install
# 查看
powershell -ExecutionPolicy Bypass -File tools\install-autostart.ps1 status
# 注销
powershell -ExecutionPolicy Bypass -File tools\install-autostart.ps1 uninstall
```

后端自启走 `tools/autostart.py`：**延迟 45 秒**启动（等系统与网络就绪）、日志重定向、
**幂等**（已经在跑就不重复起）、`--check` 只体检不启动。

## 5. 控制台

- 本地 Web 服务 + Electron 托盘壳（关窗口即收托盘，不打扰）；
- 页面：**服务状态 / 模型选择 / 功能开关 / 人格与工具 / 微信绑定 / 记忆维护 / Token 用量 / 日志**；
- 能力：扫码绑定微信、模型切换与故障转移状态、工具挂载可行性与一键挂载、动机长度与压缩参数、
  记忆维护（清空时间线/图谱、清空上下文与出站队列）、真实探活（不是"看端口在不在"，而是发 HTTP 试探）；
- 重启后端后会**轮询等它真的起来**再回报，不撒谎。

## 6. 常用排障

| 现象 | 先看哪里 |
|---|---|
| 没回复 / 回复慢 | `runtime/harness-run.log`、`runtime/llm-probe.log`（每条事件带 usage） |
| 消息收得到发不出 | 平台发送窗口（见《接口与微信平台约束.md》），停放结果用 `bridge_results` 取 |
| 摘要/图谱不更新 | 是否真的"空闲 ≥3 小时"；`runtime/gemma-server.log`；显存闸门是否等不到 |
| 绑定失效 | 重新 `python weixin_login.py` 扫码；控制台"微信绑定"页 |
| 两个消费者抢账号 | OpenClaw 隔离 preflight 会直接拒绝启动并说明原因 |

## 7. 隐私与安全（务必读）

### 7.1 不进仓库的内容

| 内容 | 为什么 |
|---|---|
| `config/secrets.json` | 全部密钥（API Key / 微信 token / 语音凭据） |
| `config/modelConfig.json` | 含账号标识（botId 等）与部署细节 |
| `config/weixinProfile.patch.yml` | 含**人格提示词正文** |
| `runtime/`、`*.log` | 日志含聊天内容、账号指纹、模型用量 |
| 时间线 / 图谱 / 状态库 | 真实聊天记录与人物关系（位于用户目录，不在项目里） |
| `备份/`、`审计产物/` | 历史快照，可能残留旧配置 |

### 7.2 工程上的其他措施

1. **日志不写明文账号**：只写 `sha256(token)` 的 12 位短指纹（形如 `acct-xxxxxxxxxxxx`，不可逆）；
2. **密钥集中一个文件**，模型定义与凭据分离，启动时合并注入；
3. **备份只备代码与输出**：密钥、人格提示词、数据库都不随备份走；
4. **审计方法**：以真实密钥值为指纹全库扫描（**不要**用占位值当指纹——曾经用 `local-only`
   这种占位串当指纹，误改了 8 个上游文档；教训：占位值会合法出现在源码里）。

### 7.3 公开前自检清单

- [ ] 仓库是 private？
- [ ] `git status` 里没有任何 `.json` 密钥、补丁人格文件、日志、数据库；
- [ ] 全库搜过 token / API Key 的真实值（**不是**搜 `sk-` 这种前缀）；
- [ ] 人格提示词正文不在任何提交里；
- [ ] 时间线/图谱数据目录不在仓库内。

## 8. 备份与回滚

- 备份目录格式：`工程名 + vX.X`，内含 md 说明该版本特点与时间；
- **只备代码与输出**，不整包拷贝；
- 大规模改动前先备份，保证可回滚。
